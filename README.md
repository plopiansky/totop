# totop

אתר לשמירת מפתחות TOTP, עם הקראת הקוד בטלפון דרך ימות המשיח.

## הרצה
```
export YEMOT_SECRET=$(openssl rand -hex 16)
npm start
```
משתני סביבה: `PORT`, `DATA_DIR`, `TOTP_ENC_KEY` (64 תווי hex, אופציונלי), `SECURE_COOKIE=1` (מאחורי HTTPS).
בלי `TOTP_ENC_KEY` נוצר מפתח הצפנה בקובץ `data/.enckey`. אל תאבדו אותו, בלעדיו המפתחות לא ניתנים לפענוח.

## חיבור לימות המשיח
בשלוחה (`ext.ini`) שתכוון לשרת:
```
type=api
api_link=https://הדומיין-שלכם/yemot/<YEMOT_SECRET>
```
השרת חייב להיות נגיש מהאינטרנט ב-HTTPS.

## שיחה
שם משתמש, סיסמה, (בחירת מפתח אם יש כמה), והקראת הקוד. הקשה על 1 משמיעה שוב.
שם המשתמש והסיסמה בספרות בלבד, כדי שאפשר יהיה להקיש אותם בטלפון.
